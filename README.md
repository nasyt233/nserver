# nserver

nserver 一个多功能服务端管理工具
- 由 `NAS油条` 个人开发
- 覆盖mc,mindustry,sfs,phira,frp等管理
- 适用于绝大多数linux发行版与termux终端


## 快速开始

### 一键安装脚本

```bash
bash -c "$(curl -L https://raw.gitcode.com/nasyt/nserver/raw/main/install.sh)"
```

## 使用

```bash
nserver     # 直接进入工具
nserver -h  # 查看帮助
```
